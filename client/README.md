# Fiore E-Commerce - Frontend (Client)

Estrutura base para desenvolvimento da interface do e-commerce de perfumes **Fiore**.

## 🛠️ Tecnologias Recomendadas / Configuradas
- **React 18 / 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (ícones)

## 🚀 Como Iniciar

1. Entre no diretório do cliente:
   ```bash
   cd client
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. O frontend estará disponível em: [http://localhost:5173](http://localhost:5173).

## 📡 Integração com a API
A API do backend (`/server`) roda por padrão na porta `3333` ([http://localhost:3333](http://localhost:3333)).
Configure variáveis de ambiente no arquivo `.env` do client se necessário (`VITE_API_URL=http://localhost:3333`).
